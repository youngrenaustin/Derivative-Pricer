This is a monte-carlo simulation call option pricer. The Vectored Pricing is the base. The factor based correlated monte carlo is the extension. 
Use the IV pull to get implied volatility from ALPACA. Follow steps and match the actual calls. 
I made this to learn more quant techniques.
It back tests all of the prices with Black Scholes closed formulas. 
Uses Python, Pandas, Numpy, MatplotLib, yfinance, alpaca-py.
